# S / P 销售说明

## 给客户看的日文对照

| 比較 | S Simple — 49,800円相当 | P Pro — 98,000円相当 |
| --- | --- | --- |
| 役割 | まず、信頼される一枚を。 | 店らしさを、予約につなげる。 |
| 構成 | 必要な情報を一ページに整理 | 物語・空間・予約まで設計 |
| メニュー | おすすめを6品掲載 | コース・焼き物・一品・ドリンクを分類 |
| 予約 | 電話と地図へすぐ移動 | 独立した予約案内＋スマホ固定導線 |
| 言語 | 日本語 | 日本語＋英語の重要ポイント |
| 向いている店 | まず正式な店の入口が必要 | 雰囲気と客単価まで伝えたい |

客户沟通重点：S 不是“低配模板”，而是最短时间建立正式手机门面的产品；P 多出的价格对应信息结构、店铺气质、预约转化与双语重点，不只是视觉装饰。

## 演示话术（先 S，后 P）

1. 先打开 S，停在首屏：说明 3 秒内能看到店名、地区、营业日、电话与地图，适合“先拥有一个正式官网门面”。
2. 下滑到菜单和来店信息：指出老板最常被问的“吃什么、多少钱、在哪里、几点开、怎么联系”都能在 30 秒内找到。
3. 再打开 P，停在首屏：让客户感受更强的排版、空间氛围与“预约”主动作。
4. 下滑指出三个价格差异：
   - 结构：P 增加店铺故事、空间与独立预约区；
   - 内容：P 菜单从 6 个重点菜升级为 4 个完整分类；
   - 转化：P 有手机固定预约 / 电话栏、规则说明与英语要点。
5. 收尾问句：`今のお店には、まず分かりやすい入口が必要ですか。それとも、雰囲気まで伝えて予約につなげたいですか。`

## URL 占位

- 入口：https://YOUR-DOMAIN.example/sales/
- S：https://YOUR-DOMAIN.example/sales/s/
- P：https://YOUR-DOMAIN.example/sales/p/

正式发信前替换域名，并用手机无痕窗口点开三条 URL。夜凪食堂是制作示例，不要把虚构地址、电话或 Instagram 当成真实店铺资料发送。
