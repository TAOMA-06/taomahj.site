Themes

不是博客列表，而是持续形成判断的脉络。

我把作品、实验和笔记放在同一条线索里看：它们回答的不是“做了什么”，而是“为什么这样做值得”。

01

AI 工作流

当模型越来越强，人的判断还应该留在哪里？

我更关心可解释、可复用、可被人接管的 AI 流程，而不是一次性的炫技输出。

Ollama / agents / memory / practical tooling

02

自动化与系统

怎样让复杂系统从“能跑”变成“能被理解”？

自动化不是把人拿掉，而是把重复、脆弱和不可见的部分整理成稳定结构。

control / Linux / hardware-minded engineering

03

个人工具

一个小工具怎样避免变成又一个临时玩具？

我偏好轻、清楚、长期可维护的界面，让工具在日常里安静地留下来。

local-first apps / browser utilities / calm interfaces

Selected Works as Arguments

01

MixFlow

配方数据怎样从列表变成可探索的知识界面？

MixFlow 不是为了展示一个花哨应用，而是在证明：好的工具应该让数据变得轻、清楚、可回到。

02

Perler Bead

图像处理工具怎样保留材料感，而不是只输出结果？

Perler Bead 代表一种偏好：技术转换应该尊重媒介，而不是把所有东西压成同一种屏幕效果。

03

持物记录

记录物品时，工具怎样承载时间而不是制造负担？

持物记录把工具放慢一点：不是催促用户输入更多，而是给记忆留下一个稳定容器。

04

Gallery

媒体浏览怎样做到低干扰，同时仍然可维护？

Gallery 是一个小型内容系统实验：好的展示页应该让对象本身成为主角。
